# Recessed Track & Downlight Pre-Embedding (无主灯预埋)

## English (EN)

### Overview
"Mainless lighting" (无主灯) replaces the central chandelier with distributed magnetic track spots and trimless recessed downlights. The entire visual effect depends on what happens **before** the ceiling boards close: rails and frames must be embedded dead-straight, dead-level, and flush with the final plaster plane. In Indonesia, where ceiling crews and electricians work as separate trades, this coordination is the single most common failure point of minimalist interiors.

### Process Parameters
- **Track straightness**: ≤ 2mm deviation per 3m run ⚠️
- **Track flush tolerance**: rail face flush with finished ceiling plane, ±0.5mm ⚠️
- **Downlight spacing**: 800–1200mm typical, per lighting design ⚠️
- **Clearance above rail**: ≥ 50mm for heat dissipation ⚠️

### Step-by-Step Workflow
1. **Lighting Layout Confirmation**  
   Transfer the reflected ceiling plan (RCP) to site: track runs, downlight positions, switching zones. Confirm against furniture plan.  
   - *Tools*: RCP drawings, laser level, measuring tape.  
   - *Acceptance*: Owner/designer sign-off on marked positions.
2. **Electrical Rough-in**  
   Run conduits and pull wires to each track feed point and downlight loop; leave 300mm service loops ⚠️.  
   - *Tools*: Conduit, wire puller, junction boxes.  
   - *Acceptance*: Circuit test pass; zones match switch plan (links to [[electrical-switch-socket-installation]]).
3. **Ceiling Framing Coordination**  
   Adjust light-gauge steel framing so no main/furring channel crosses a track run or downlight position.  
   - *Tools*: Refer to [[floating-suspended-ceiling]].  
   - *Acceptance*: Zero framing conflict on layout overlay check.
4. **Track Rail Mounting**  
   Fix magnetic track rails to structural slab or reinforced framing with dedicated hangers; laser-level along the full run.  
   - *Tools*: Laser level, dedicated hangers, torque driver.  
   - *Acceptance*: Straightness ≤ 2mm/3m ⚠️; hanger spacing ≤ 600mm ⚠️.
5. **Trimless Frame Installation**  
   Set trimless downlight frames at marked points; verify frame face plane equals finished ceiling plane minus board thickness.  
   - *Tools*: Depth gauge, laser plane.  
   - *Acceptance*: Plane error ≤ 0.5mm ⚠️.
6. **Board Closing Around Embeds**  
   Close gypsum boards; cut openings precisely against rails/frames with dedicated hole saws.  
   - *Tools*: Hole saw set, utility knife.  
   - *Acceptance*: Board edge gap to profile ≤ 2mm, uniform ⚠️.
7. **Plaster & Edge Finishing**  
   Apply joint compound to profile edges with mesh tape reinforcement; sand flush.  
   - *Tools*: Taping knives, mesh tape, sanding block.  
   - *Acceptance*: No visible ridge at profile edge under raking light.
8. **Electrical Fit-off & Test**  
   Install track adapters, spots, and downlight modules; test all zones and dimming curves.  
   - *Tools*: Multimeter, lux meter (optional).  
   - *Acceptance*: All circuits energized; dimming smooth; no flicker ⚠️.

### Quality Control (QC) Standards
| Criterion | Standard | Note |
| :--- | :--- | :--- |
| Track straightness | ≤ 2mm per 3m ⚠️ | Laser line check |
| Profile flush | ±0.5mm to ceiling plane ⚠️ | Feeler + straightedge |
| Edge cracking | Zero cracks at profile edges after 28 days ⚠️ | Raking light inspection |
| Opening precision | Board-to-profile gap ≤ 2mm uniform ⚠️ | Visual + caliper |
| Electrical | All zones switch/dim correctly | Zone-by-zone test |

### Common Issues & Prevention
| Issue | Cause | Solution |
| :--- | :--- | :--- |
| Track visibly wavy | Hangers uneven / no laser leveling | Laser-level full run before fixing; hanger spacing ≤ 600mm |
| Cracks at profile edge | No mesh tape / board gap too wide | Mandatory mesh reinforcement; gap ≤ 2mm |
| Rail not flush | Frame plane set without board-thickness allowance | Set plane = finished plane − board thickness |
| Dead spots after closing | Wiring loop too short / buried junction | 300mm service loops; junction map photographed before closing ⚠️ |
| Framing blocks track | Ceiling and electrical not coordinated | Overlay check at Step 3, mandatory |
| Rainy-season condensation in rails | Humid ceiling void | Ventilate void; check before fit-off ⚠️ |

## 中文 (ZH)

### 概览
无主灯设计用分布式磁吸轨道射灯与无边框防眩筒灯取代主吊灯。全部视觉效果取决于**封板之前**的工序：轨道与预埋框必须横平竖直、与最终批灰面齐平。在印尼，吊顶班组与电工是两个独立工种，这种协同正是极简风翻车的头号高发点。

### 工艺参数
- **轨道顺直度**：3m 内偏差 ≤ 2mm ⚠️
- **轨道齐平度**：轨道面与完成吊顶面齐平，±0.5mm ⚠️
- **射灯间距**：常规 800–1200mm，按灯光设计 ⚠️
- **轨道上方净空**：≥ 50mm（散热）⚠️

### 工序流程
1. **灯光定位确认**  
   将天花灯位图（RCP）落地放线：轨道走向、筒灯点位、开关分区，与家具图核对。  
   - *工具*：RCP 图纸、激光水平仪、卷尺。  
   - *验收*：业主/设计师签字确认点位。
2. **电气预埋**  
   布管穿线至各轨道供电点与筒灯回路，预留 300mm 检修线余量 ⚠️。  
   - *工具*：线管、穿线器、接线盒。  
   - *验收*：回路测试通过；分区与开关图一致（关联 [[electrical-switch-socket-installation]]）。
3. **吊顶龙骨协同**  
   调整轻钢龙骨排布，确保主/副龙骨不穿越轨道走向与筒灯点位。  
   - *工具*：参照 [[floating-suspended-ceiling]]。  
   - *验收*：叠加放线检查零冲突。
4. **轨道安装**  
   磁吸轨道用专用吊件固定于结构板或加强龙骨，全程激光找平。  
   - *工具*：激光水平仪、专用吊件、扭矩螺丝刀。  
   - *验收*：顺直度 ≤2mm/3m ⚠️；吊件间距 ≤600mm ⚠️。
5. **无边框预埋框安装**  
   按点位安装无边框筒灯预埋框，框面标高 = 完成面 − 板材厚度。  
   - *工具*：深度规、激光平面。  
   - *验收*：平面误差 ≤0.5mm ⚠️。
6. **封板开口**  
   封石膏板，沿轨道/预埋框用专用开孔器精确开口。  
   - *工具*：开孔器组、美工刀。  
   - *验收*：板边与型材缝隙 ≤2mm 且均匀 ⚠️。
7. **批灰收口**  
   型材边缘贴网格带加强批嵌，打磨齐平。  
   - *工具*：批刀、网格带、砂架。  
   - *验收*：侧光下型材边缘无可见棱线。
8. **电气安装与调试**  
   装轨道适配器、射灯、筒灯模组，逐区测试调光曲线。  
   - *工具*：万用表、照度计（可选）。  
   - *验收*：全部回路通电；调光顺滑无频闪 ⚠️。

### 验收标准 (QC)
| 验收项 | 标准 | 备注 |
| :--- | :--- | :--- |
| 轨道顺直度 | ≤2mm/3m ⚠️ | 激光线检查 |
| 型材齐平 | ±0.5mm ⚠️ | 塞尺+靠尺 |
| 边缘开裂 | 28 天后型材边缘零裂缝 ⚠️ | 侧光检查 |
| 开口精度 | 板与型材缝 ≤2mm 均匀 ⚠️ | 目测+卡尺 |
| 电气 | 各分区开关/调光正确 | 逐区测试 |

### 常见问题与避坑
| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 轨道波浪弯 | 吊件不平/未激光找平 | 固定前全程激光找平，吊件间距 ≤600mm |
| 型材边缘开裂 | 未贴网格带/板缝过宽 | 强制网格带加强；缝 ≤2mm |
| 轨道不齐平 | 预埋框未扣除板厚 | 标高 = 完成面 − 板厚 |
| 封板后死灯 | 线余量不足/接头被埋 | 留 300mm 余量；封板前拍照留底 ⚠️ |
| 龙骨挡轨道 | 吊顶与电气未协同 | Step 3 叠加检查强制 |
| 雨季轨道内凝露 | 吊顶空腔潮湿 | 空腔通风；安装灯具前检查 ⚠️ |
