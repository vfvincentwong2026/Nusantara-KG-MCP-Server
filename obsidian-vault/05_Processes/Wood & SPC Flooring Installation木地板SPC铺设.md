# Wood & SPC Flooring Installation (木地板/SPC 铺设工艺)

## English (EN)

### Overview
Floating floors (laminate/engineered/SPC) are fast to install and unforgiving to shortcuts: every failure — buckling, squeaking, gapping — traces back to substrate flatness, moisture, or missing expansion gaps. In Indonesia the humidity multiplies all three risks. The good news: with disciplined prep, straight lay is a standardized operation well within Indonesian skilled labor.

### Process Parameters
- **Substrate flatness**: ≤ 3mm per 2m ⚠️
- **Substrate moisture**: ≤ 12% CM reading before laying ⚠️
- **Expansion gap**: 8–10mm at all walls and fixed elements ⚠️
- **Acclimatization**: 48–72 hours on site before laying ⚠️

### Step-by-Step Workflow
1. **Substrate Check**  
   Flatness ≤3mm/2m and moisture test; grind or self-level if exceeded; reject damp substrate.  
   - *Tools*: 2m straightedge, moisture meter.  
   - *Acceptance*: Both readings pass — no waiver in rainy season.
2. **Moisture Barrier**  
   Lay PE film (0.2mm) with 200mm overlaps, taped seams; up the wall 20mm, trimmed later.  
   - *Tools*: PE film, tape.  
   - *Acceptance*: No tears; seams fully taped.
3. **Underlay**  
   Roll out underlay (2-3mm foam/IXPE) perpendicular to plank direction, butt joints taped.  
   - *Tools*: Underlay, tape, cutter.  
   - *Acceptance*: Flat, no overlaps.
4. **Layout Planning**  
   Plan plank direction (along main light/long axis), stagger pattern ≥300mm, first/last row width ≥ 50mm ⚠️.  
   - *Tools*: Measuring tape, spacers.  
   - *Acceptance*: Layout sketch confirmed; no sliver cuts.
5. **First Rows**  
   Set spacers for 8-10mm expansion; lay first two rows perfectly straight — they govern the whole room.  
   - *Tools*: Spacers, tapping block, pull bar.  
   - *Acceptance*: Straight edge check along row two.
6. **Field Laying**  
   Click-lock at 30-45° angle, tap joints fully home; check every 3 rows for drift.  
   - *Tools*: Tapping block, mallet.  
   - *Acceptance*: Joints closed, no lifted edges; drift ≤ 2mm per 5m ⚠️.
7. **Herringbone (Premium, China skilled)**  
   45° herringbone from a true center line; border and transition details.  
   - *Tools*: Miter saw, laser, jig.  
   - *Acceptance*: Pattern centered; joints tight throughout.
8. **Trims & Handover**  
   Install baseboards ([[metal-baseboard-installation]]) or coordinate [[minimalist-trimless-edge]]; remove spacers; final clean.  
   - *Tools*: Baseboard tools, vacuum.  
   - *Acceptance*: Expansion gaps fully concealed; walk-test silent.

### Quality Control (QC) Standards
| Criterion | Standard | Note |
| :--- | :--- | :--- |
| Substrate flatness | ≤ 3mm/2m ⚠️ | Pre-gate |
| Expansion gap | 8–10mm continuous ⚠️ | Spacer check before trims |
| Joint integrity | No open/lipped joints | Feel test |
| Walk test | Silent, no vertical movement ⚠️ | Full-area walk |
| Pattern drift | ≤ 2mm per 5m ⚠️ | Straightedge |

### Common Issues & Prevention
| Issue | Cause | Solution |
| :--- | :--- | :--- |
| Buckling (起拱) | Expansion gap too small / wet season swelling | 8-10mm gaps mandatory; rainy season use upper bound ⚠️ |
| Squeaking | Substrate uneven / underlay overlapped | Enforce flatness pre-gate; butt-joint underlay |
| Open joints after weeks | Joints not tapped home / drift | Tap every joint; check drift every 3 rows |
| Swollen edges | Water mopping / no moisture barrier | PE barrier mandatory; damp-mop only ⚠️ |
| Sliver cuts at walls | No layout planning | First/last row ≥ 50mm rule |
| Fading near windows | UV exposure (SPC) | Curtains/film in sun-exposed zones ⚠️ |

## 中文 (ZH)

### 概览
悬浮式地板（复合/实木复合/SPC）安装快，但对偷工零容忍：所有失败——起拱、响声、开缝——都可追溯到基层平整度、潮气或伸缩缝缺失。印尼高湿把这三类风险全部放大。好消息是：基层准备到位后，直拼是印尼技工完全胜任的标准化作业。

### 工艺参数
- **基层平整度**：≤3mm/2m ⚠️
- **基层含水率**：铺设前 ≤12%（CM 仪）⚠️
- **伸缩缝**：周边及固定构件处 8–10mm ⚠️
- **现场适应**：铺设前 48–72 小时 ⚠️

### 工序流程
1. **基层检查**  
   平整度 ≤3mm/2m + 含水率测试；超标打磨或自流平；潮湿基层拒收。  
   - *工具*：2m 靠尺、含水率仪。  
   - *验收*：双指标通过——雨季无豁免。
2. **防潮层**  
   铺 0.2mm PE 膜，搭接 200mm，接缝贴胶；上墙 20mm 后裁切。  
   - *工具*：PE 膜、胶带。  
   - *验收*：无破损；接缝全贴。
3. **地垫**  
   2-3mm 地垫垂直于板向铺设，平接贴胶。  
   - *工具*：地垫、胶带、裁刀。  
   - *验收*：平整无重叠。
4. **排版规划**  
   板向顺主光源/长轴；错缝 ≥300mm；首末排板宽 ≥50mm ⚠️。  
   - *工具*：卷尺、缝隙卡子。  
   - *验收*：排版确认；无窄条切割。
5. **首两排**  
   卡 8-10mm 伸缩缝；首两排绝对平直——它们统治整个房间。  
   - *工具*：卡子、敲块、回力钩。  
   - *验收*：第二排直边检查通过。
6. **大面铺设**  
   30-45° 锁扣入槽，敲实每缝；每 3 排检查跑偏。  
   - *工具*：敲块、橡皮锤。  
   - *验收*：缝闭合无翘边；跑偏 ≤2mm/5m ⚠️。
7. **人字拼（高端，中国技工）**  
   45° 人字拼自真实中线起铺；收边与过渡细部。  
   - *工具*：斜切锯、激光、靠模。  
   - *验收*：图案居中；全缝紧密。
8. **收边交付**  
   装踢脚线（[[metal-baseboard-installation]]）或衔接 [[minimalist-trimless-edge|极简收口]]；拔卡子；终清洁。  
   - *工具*：踢脚工具、吸尘器。  
   - *验收*：伸缩缝全遮蔽；行走测试无声。

### 验收标准 (QC)
| 验收项 | 标准 | 备注 |
| :--- | :--- | :--- |
| 基层平整度 | ≤3mm/2m ⚠️ | 前置门 |
| 伸缩缝 | 8–10mm 连续 ⚠️ | 收边前卡尺检查 |
| 接缝完好 | 无开缝/错台 | 手触检查 |
| 行走测试 | 无声、无上下浮动 ⚠️ | 全区行走 |
| 图案跑偏 | ≤2mm/5m ⚠️ | 靠尺 |

### 常见问题与避坑
| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 起拱 | 伸缩缝不足/雨季膨胀 | 8-10mm 强制；雨季取上限 ⚠️ |
| 响声 | 基层不平/地垫重叠 | 平整度前置门；地垫平接 |
| 数周后开缝 | 缝未敲实/跑偏 | 每缝敲实；3 排一检 |
| 边缘泡发 | 湿拖把/无防潮层 | PE 膜强制；半干拖 ⚠️ |
| 墙边窄条 | 未排版 | 首末排 ≥50mm 规则 |
| 窗边褪色 | 紫外线暴晒（SPC） | 暴晒区窗帘/贴膜 ⚠️ |
