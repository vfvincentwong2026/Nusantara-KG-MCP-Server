# Custom Built-in Wardrobe / Millwork Installation (定制集成柜体/木作安装)

> 🤖 本文件为精密木作工法模板，带 ⚠️ 参数依据《木结构工程施工质量验收规范 GB 50206》及印尼SNI 03-6831-2002木制品耐腐标准。白蚁防治与防潮通风为印尼木作的生命线。

## English (EN)

### Overview

Built-in cabinetry in Indonesia faces two existential threats: **termites** and **dimensional instability (swelling/shrinkage)** due to 80%+ relative humidity. This protocol mandates the use of **MR-grade (moisture-resistant) plywood or HDF** with anti-termite pressure-treatment, a **30–50mm back-ventilation cavity** to prevent condensation, and **304 stainless steel or zinc-alloy hardware** with anti-rust coating. All panels must be acclimatized to the installation site for at least 7 days.

### Critical Process Parameters

| Parameter | Specification | Note |
| :--- | :--- | :--- |
| **Panel Material** | MR-grade plywood (≥ 15mm) or anti-termite HDF | **Solid timber strictly prohibited** (termite bait) |
| **Panel Moisture Content (Pre-install)** | **≤ 12%** ⚠️ | Acclimatize on-site for 7 days |
| **Back Ventilation Cavity** | 30–50mm gap between cabinet back and wall | Prevents condensation/mold |
| **Wall Anchors** | Heavy-duty expansion bolts (φ8–10mm) | Seismic-grade; not plastic plugs |
| **Hardware Grade** | 304 Stainless Steel (hinges, handles, drawer slides) | Coastal Bali/Java mandates 316 for exterior |
| **Shelf Deflection Limit** | ≤ 1.5mm per 300mm span ⚠️ | Under full load (20kg) |
| **Door Gap Tolerance** | 2–3mm uniform gap ⚠️ | Prevents binding due to humidity swelling |

### Step-by-Step Workflow

**Step 1: Site Measurement & Wall Check**
- *Description*: Measure the actual installation space (width, height, depth). Check wall verticality (≤3mm/2m) and floor flatness (≤2mm/2m). Excessive deviations require pre-screeding or wall-putty correction before cabinet installation.
- *Tools*: Laser distance meter, 2m straightedge, plumb rule.
- *Acceptance*: Wall plumb ≤3mm/2m; floor flat ≤2mm/2m.

**Step 2: Panel Acclimatization & Moisture Check**
- *Description*: Deliver all pre-fabricated panels to the site and stack them flat with spacers. Allow **7 days** of acclimatization to the room's ambient humidity. **Measure panel moisture content daily; do not install until ≤12% MC**.
- *Tools*: Pin-type moisture meter, spacers.
- *Acceptance*: All panels ≤12% MC; no warping or twisting.

**Step 3: Wall Marking & Back-Ventilation Cavity Layout**
- *Description*: Use a laser level to mark the cabinet's final position on the wall. Designate the 30–50mm ventilation gap at the back—this is achieved using spacer blocks or a dedicated wall-hanging rail system.
- *Tools*: Laser level, pencil, chalk line.
- *Acceptance*: All marks level; gap allowance consistently 30–50mm.

**Step 4: Wall-Mounted Hanging Rail / Fixing Bracket Installation**
- *Description*: Install heavy-duty wall-hanging rails or L-brackets using **expansion anchor bolts (φ8–10mm)** drilled into the structural wall. Anchors must penetrate at least 60mm into concrete/brick. Do not use ordinary plastic dowels — they will pull out under the dead load of the cabinet.
- *Tools*: Hammer drill, torque wrench, impact driver.
- *Acceptance*: Anchors tightened to specified torque; rail perfectly level.

**Step 5: Base Cabinet / Carcass Assembly**
- *Description*: Assemble the cabinet boxes using **dowel pins + cam-lock fittings** and **waterproof PVA wood glue** (D3 grade). Squareness must be maintained—measure diagonals for each box (tolerance ≤2mm).
- *Tools*: Dowel drilling jig, cam-lock driver, rubber mallet, measuring tape.
- *Acceptance*: Boxes square; joints tight; no gaps.

**Step 6: Cabinet Hanging & Fixing to Wall**
- *Description*: Lift and hang the assembled carcass onto the wall rails. Level and plumb the entire unit, then secure it to the wall anchors through the back panel's fixing points. Interconnect multiple modules using connector bolts to form a single rigid block.
- *Tools*: Spirit level, laser level, impact driver.
- *Acceptance*: Cabinet plumb (≤1mm/2m); all modules coplanar.

**Step 7: Adjustable Legs / Leveling Feet Installation (for floor-standing units)**
- *Description*: For floor-standing cabinets, install heavy-duty adjustable legs (≥80mm height) with anti-rust coating. Adjust each leg to level the cabinet and elevate it off the floor—this prevents capillary moisture wicking and allows for cleaning access.
- *Tools*: Adjustable wrench, spirit level.
- *Acceptance*: Cabinet leveled; all legs bearing evenly; elevated ≥80mm from finished floor.

**Step 8: Door, Drawer & Hardware Installation**
- *Description*: Install doors using **304 stainless steel hinges** with soft-close mechanisms. Mount drawer slides (stainless steel ball-bearing type). Adjust all hardware to ensure smooth operation. Door gaps should be uniform (2–3mm) to accommodate seasonal humidity swelling.
- *Tools*: Screwdriver, hinge-adjustment tool, measuring calipers.
- *Acceptance*: Doors open/close smoothly; gaps consistent; no friction between doors.

**Step 9: Edge Banding & Joint Sealing (Moisture Barrier)**
- *Description*: Apply **PVC/ABS edge-banding** to all exposed panel edges (minimum thickness 1.0mm) and seal seams with **flexible silicone sealant** where cabinets meet the wall/floor—this prevents moisture ingress and termite entry points.
- *Tools*: Edge-banding trimmer, silicone gun, caulking tool.
- *Acceptance*: All edges fully sealed; no raw substrate exposed; silicone smooth and continuous.

### Quality Control (QC) Standards

| Criterion | Standard | Inspection Method |
| :--- | :--- | :--- |
| **Panel Moisture Content** | ≤ 12% (at installation) | Pin moisture meter |
| **Cabinet Plumb / Level** | ≤ 1mm per 2m | Laser level + feeler gauge |
| **Door Gap** | 2–3mm uniform (±0.5mm tolerance) | Caliper |
| **Hardware Smoothness** | No sticking, no noise under 10kg load | Manual operation test |
| **Back Ventilation Gap** | 30–50mm continuous | Tape measure / visual |
| **Edge Sealing** | 100% coverage; no raw edges exposed | Visual + white-glove wipe |

### Common Issues & Prevention (Indonesia-Specific)

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **Termite Infestation** | Solid timber used / No anti-termite treatment / Contact with ground | **Ban solid timber**; use pressure-treated HDF; maintain 80mm floor clearance |
| **Panel Swelling (Door jamming)** | Panel MC >12% / No edge-sealing | Mandate moisture test; enforce edge-banding on all sides |
| **Mold/Mildew Behind Cabinets** | No ventilation gap / Condensation buildup | **Enforce** 30–50mm back cavity; install ventilation grilles |
| **Hardware Rusting** | Zinc-plated steel used (cheap type) | Use **304 stainless steel**; 316 for coastal areas |
| **Cabinet Separation from Wall (Seismic)** | Plastic wall anchors / Insufficient depth | Use φ10 expansion bolts with ≥60mm embedment; add wall tie-brackets |
| **Warped Doors** | Panel moisture imbalance / Direct sunlight | Acclimatize for full 7 days; avoid window-facing installations without UV blinds |

## 中文 (ZH)

### 概览

印尼嵌入式柜体面临两大生存威胁：**白蚁**和因相对湿度>80%导致的**尺寸不稳定（膨胀/收缩）**。本规程强制使用**防潮级（MR）胶合板或抗白蚁高密度板**、背部**30–50mm通风空腔**（防冷凝）、以及**304不锈钢或锌合金防腐五金件**。所有板材必须在安装现场适应环境至少7天。

### 核心工艺参数

| 参数 | 规格指标 | 备注 |
| :--- | :--- | :--- |
| **板材类型** | MR级胶合板（≥15mm）或抗白蚁HDF | **严禁使用实木**（白蚁诱饵） |
| **板材含水率（安装前）** | **≤ 12%** ⚠️ | 现场适应7天 |
| **背部通风空腔** | 柜体背板距墙30–50mm | 防冷凝/防霉 |
| **墙体锚栓** | 重型膨胀螺栓（φ8–10mm） | 抗震级；非塑料胀栓 |
| **五金件等级** | 304不锈钢（铰链/拉手/滑轨） | 巴厘岛/爪哇沿海室外用316 |
| **层板挠度限值** | 每300mm跨度≤1.5mm ⚠️ | 满载（20kg）条件下 |
| **门板间隙公差** | 2–3mm均匀缝隙 ⚠️ | 防止高湿膨胀后卡滞 |

### 工序流程

**Step 1: 现场测量与墙面检测**
- *描述*：实测安装空间尺寸（宽/高/深）。检测墙面垂直度（≤3mm/2m）及地面平整度（≤2mm/2m）。偏差过大时需先进行墙面找平或冲筋处理，方可安装柜体。
- *工具*：激光测距仪、2m靠尺、垂直靠尺。
- *验收*：墙面垂直≤3mm/2m；地面平整≤2mm/2m。

**Step 2: 板材适应环境与含水率检测**
- *描述*：将所有预制板材运至现场，平放并垫置垫块。**适应环境至少7天**。**每日检测板材含水率，须降至≤12%后方可安装**。
- *工具*：针式含水率仪、垫块。
- *验收*：所有板材≤12%；无翘曲扭曲。

**Step 3: 墙面放线与背部通风空腔定位**
- *描述*：使用激光水平仪在墙面标记柜体最终位置。背部预留30–50mm通风间隙——通过垫块或专用挂墙导轨系统实现。
- *工具*：激光水平仪、铅笔、墨斗。
- *验收*：标记平直；间隙预留一致（30–50mm）。

**Step 4: 挂墙导轨/固定支架安装**
- *描述*：在结构墙上钻孔，安装**重型膨胀锚栓（φ8–10mm）**，固定挂墙导轨或L型支架。锚栓必须深入混凝土/砖墙至少60mm。**严禁使用普通塑料胀栓**——无法承受柜体自重荷载。
- *工具*：冲击钻、扭力扳手、冲击起子。
- *验收*：锚栓扭矩达标；导轨绝对水平。

**Step 5: 柜体预组装（箱体）**
- *描述*：使用**圆木榫+偏心连接件**及**防水PVA木工胶（D3级）**组装柜体箱体。必须保证方正度——测量每个箱体对角线（公差≤2mm）。
- *工具*：圆木榫定位钻模、偏心轮起子、橡皮锤、卷尺。
- *验收*：箱体方正；接缝紧密；无缝隙。

**Step 6: 柜体挂装与墙体固定**
- *描述*：将组装好的箱体抬起，挂装于墙面导轨上。使用水平仪/激光仪调整至完全水平垂直后，通过背板固定点用螺丝锁固于墙体锚栓。多个模块间用连接螺栓串联成刚性整体。
- *工具*：水平尺、激光水平仪、冲击起子。
- *验收*：柜体垂直（≤1mm/2m）；所有模块共面。

**Step 7: 可调脚/调平脚安装（落地柜）**
- *描述*：落地柜安装重型可调脚（高度≥80mm），带防腐涂层。调节每支脚使柜体水平，并使其离地抬高——此举可阻断毛细潮气上返，并便于清洁。
- *工具*：活动扳手、水平尺。
- *验收*：柜体水平；各脚均匀承重；离完成面≥80mm。

**Step 8: 门板、抽屉及五金安装**
- *描述*：安装门板，使用**304不锈钢阻尼铰链**。安装抽屉滑轨（不锈钢滚珠式）。精细调节所有五金件，确保开合顺畅。门缝须均匀（2–3mm），以容纳季节性湿度膨胀。
- *工具*：螺丝刀、铰链调节工具、游标卡尺。
- *验收*：门板开合顺畅；缝隙均匀；无摩擦刮蹭。

**Step 9: 封边与接缝密封（防潮屏障）**
- *描述*：对所有裸露板材边缘进行**PVC/ABS封边**（厚度≥1.0mm），并在柜体与墙面/地面的交接处用**柔性防霉硅酮密封胶**填缝密封——此举可阻止潮气侵入和白蚁进入通道。
- *工具*：封边修边器、胶枪、刮缝工具。
- *验收*：所有边缘100%封闭；无基材裸露；硅胶平滑连续。

### 验收标准 (QC)

| 验收项 | 标准 | 检测方法 |
| :--- | :--- | :--- |
| **板材含水率** | ≤ 12%（安装时） | 针式含水率仪 |
| **柜体垂直/水平** | ≤ 1mm / 2m | 激光水平仪+塞尺 |
| **门板缝隙** | 2–3mm均匀（±0.5mm公差） | 卡尺 |
| **五金顺滑度** | 10kg负重下无卡顿、无异响 | 手动操作测试 |
| **背部通风间隙** | 30–50mm连续 | 卷尺/目视 |
| **封边密封** | 100%覆盖；无裸露板材边缘 | 目视+白手套擦拭 |

### 常见问题与避坑（印尼特化）

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| **白蚁蛀蚀** | 使用实木 / 未做防白蚁处理 / 直接接触地面 | **禁用实木**；使用抗白蚁HDF；保持80mm离地间隙 |
| **板材膨胀（门板卡死）** | 板材含水率>12% / 未封边 | 强制含水率检测；所有边缘强制封边 |
| **柜后发霉** | 无通风间隙 / 冷凝水积聚 | **强制**30–50mm背部空腔；加装通风百叶 |
| **五金锈蚀** | 使用廉价镀锌钢件 | 统一用**304不锈钢**；沿海地区用316 |
| **地震脱落** | 使用塑料胀栓 / 锚固深度不足 | φ10膨胀螺栓，埋深≥60mm，加装防震连接片 |
| **门板变形翘曲** | 板材含水率不均 / 阳光直射一侧 | 足7天适应环境；避免靠窗直射（装遮光帘） |

### 关联知识（人力、材料与替代方案）

- **技术工人**：需[[millwork-specialist|精密木作/柜体专项技师]]——熟练掌握圆木榫+偏心连接件组装工艺，非普通木工。
- **主材**：[[mr-grade-plywood|MR级防潮胶合板（E0/E1级）]]、[[termite-resistant-hdf|抗白蚁高密度板]]、[[waterproof-pva-glue|D3级防水PVA胶]]。
- **五金件**：[[stainless-steel-hinges|304不锈钢阻尼铰链]]、[[stainless-steel-drawer-slides|不锈钢滚珠滑轨]]、[[expansion-bolts|抗震膨胀螺栓（φ10）]]。
- **封边密封**：[[abs-edge-banding|ABS封边条（1.0mm）]]、[[flexible-silicone|防霉硅酮密封胶]]。
- **高端替代**：[[aluminum-frame-cabinets|铝合金框架柜体]]（零白蚁风险、完全防水——推荐用于卫浴及户外厨房）。
