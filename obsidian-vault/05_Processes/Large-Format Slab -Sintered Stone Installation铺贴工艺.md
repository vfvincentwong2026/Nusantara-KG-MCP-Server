# Large-Format Slab / Sintered Stone Installation (大规格板/岩板铺贴工艺)

> 🤖 本文件为严格工艺标准模板，带 ⚠️ 的参数为行业通用推荐值，具体项目需依据瓷砖胶厂家技术说明书及结构设计复核。

---

## English (EN)

### Overview

Unlike conventional wet-method tiling, large-format slabs (dimension ≥ 1.2m on one side) and sintered stone require **structural-grade precision**. Due to their massive dead load and brittle nature, this method strictly prohibits hollow spots to prevent seismic-induced cracking. The system combines a **cement-sand leveling bed** (for substrate correction) with a **polymer-modified thin-set adhesive** (for bonding), employing a **double-buttering** technique.

### Critical Process Parameters

| Parameter | Specification | Note |
| :--- | :--- | :--- |
| **Slab Thickness** | 6–20mm | — |
| **Total Installation Height** | 20–40mm ⚠️ | Leveling bed + adhesive layer |
| **Flatness Tolerance** | **≤ 1mm / 2m** ⚠️ | Twice as strict as standard tiles |
| **Hollow Ratio** | **0% (Strictly Forbidden)** ⚠️ | Full-contact bedding required |
| **Adhesive Open Time** | ≤ 20 mins (at 30°C) ⚠️ | Indonesia's heat shortens working time |
| **Joint Width** | 1.5–3.0mm ⚠️ | Allows for seismic movement |

### Step-by-Step Workflow

**Step 1: Substrate Preparation & Leveling**
- *Description*: Grind high spots, repair cracks, and apply a cement-sand screed (1:4 ratio) to achieve a base flatness of ≤ 3mm/2m. In Indonesia's rainy season, test substrate moisture content (< 8%) before proceeding.
- *Tools*: Grinding machine, 2m straightedge, moisture meter.
- *Acceptance*: Substrate dry, flat, and free of release agents.

**Step 2: Adhesive Mixing (Dispersion)**
- *Description*: Use a high-performance polymer-modified (C2TE S1/S2 grade) adhesive. Mix strictly according to the manufacturer's water-powder ratio using a low-speed electric mixer (≤ 300 rpm). Slurry must have a creamy, non-sagging consistency.
- *Tools*: Low-speed stirrer, measuring container, viscosimeter.
- *Acceptance*: No dry powder lumps; resting time (slaking) strictly observed per datasheet.

**Step 3: Double-Buttering (Back & Substrate)**
- *Description*: Apply the adhesive to both the substrate (using a 10–12mm notched trowel) and the slab's back (using a 6–8mm notched trowel) in parallel straight lines. **This double-sided application is non-negotiable** to guarantee 100% adhesive transfer.
- *Tools*: Notched trowels (U-shape recommended), trowel.
- *Acceptance*: Ribs are uniform, continuous, and not skinned over.

**Step 4: Slab Placement & Positioning**
- *Description*: Lift the slab using professional vacuum suction cups (min. 2–4 cups depending on size). Place it onto the adhesive bed with a slight side-slip motion to collapse the adhesive ribs.
- *Tools*: Vacuum suction cups, suction lifters, adjustable tripods.
- *Acceptance*: Positioning accurate within ±1mm; no impact on edges/corners.

**Step 5: Vibration Compaction & Leveling**
- *Description*: Use an electric vibration compactor (or manual vibrating pad) to uniformly compact the slab from the center outward. Immediately insert heavy-duty leveling clips and tighten with pliers to achieve perfect flush joints. **Vibration is critical to expel trapped air**.
- *Tools*: Vibration compactor, laser level, heavy-duty leveling system (wedge/clip).
- *Acceptance*: Flatness ≤ 1mm/2m; adjacent slab lippage ≤ 0.3mm ⚠️; clips fully engaged.

**Step 6: Curing & Protection**
- *Description*: Prohibit foot traffic and point loads for **at least 48 hours** (standard 24h is insufficient for large slabs). In high-humidity conditions (> 80%), extend curing to 72 hours to prevent bond failure.
- *Tools*: Protective plywood boards, warning tapes.
- *Acceptance*: No displacement; adhesive squeeze-out has set.

**Step 7: Flexible Grouting**
- *Description*: After 72 hours, remove leveling clips and fill joints with high-performance **epoxy-based or hybrid polymer grout** (not ordinary cement grout) to accommodate micro-seismic movements.
- *Tools*: Grout float, shaping tool, sponge.
- *Acceptance*: Joints filled flush; color perfectly matched; no efflorescence.

### Quality Control (QC) Standards

| Criterion | Standard | Inspection Method |
| :--- | :--- | :--- |
| **Hollow Spots** | **0%** — any hollow spot is unacceptable | Full tapping test (coin/wooden hammer) |
| **Flatness** | ≤ 1mm gap under 2m straightedge | Feeler gauge |
| **Lippage** | ≤ 0.3mm between adjacent slabs | Dial gauge / fingertip test |
| **Adhesive Coverage** | ≥ 90% (interior), ≥ 95% (exterior/wet) | Random pull-out test |
| **Seismic Joint** | Retained width tolerance ± 0.5mm | Caliper |

### Common Issues & Prevention (Indonesia-Specific)

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **Hollow Spots** | Adhesive dried out before placement / Insufficient vibration | Mix smaller batches; use double-buttering; enforce vibration compactor use |
| **Cracking (Thermal/Seismic)** | Rigid grout used / Insufficient joint width | Use flexible epoxy grout; widen joints to 3.0mm near structural columns |
| **Slab Warping / Curling** | Uneven adhesive thickness / Sunlight exposure | Ensure uniform notched-trowel ribs; protect slab from direct sun before installation |
| **Bond Failure (Rainy Season)** | High ambient humidity diluting adhesive | Use adhesives with extended open time; measure moisture content; delay if > 85% RH |

### Related Knowledge (Labor, Materials & Alternatives)

- **[[china-skilled-labor|Chinese Skilled Labor]]**: **Mandatory** — local Indonesian labor generally lacks the specialized training for vibration compaction and suction-lifting techniques.
- **Primary Adhesive**: [[epoxy-adhesive|Epoxy-based C2TE S2 Adhesive]].
- **Grouting**: [[flexible-grout|Hybrid Polymer Grout (R2 class)]].
- **Alternative Method**: [[mechanical-anchoring-system|Mechanical Anchoring + Adhesive]] (for exterior high-rise facades).

## 中文 (ZH)

### 概览

与常规湿铺法不同，大规格板（边长≥1.2m）及岩板需要**结构级的安装精度**。因其自重极大且脆性高，此工法**严禁任何空鼓**，以防地震带开裂。本系统采用**水泥砂浆找平层**（修正基层）与**聚合物改性瓷砖胶**（粘结）结合，并强制实施**双面刮胶**工艺。

### 核心工艺参数

| 参数 | 规格指标 | 备注 |
| :--- | :--- | :--- |
| **板材厚度** | 6–20mm | — |
| **安装总厚度** | 20–40mm ⚠️ | 找平层+粘结层 |
| **平整度公差** | **≤ 1mm / 2m** ⚠️ | 为普通砖标准的2倍 |
| **空鼓率** | **0%（绝对禁止）** ⚠️ | 必须满粘 |
| **胶粘剂开放时间** | ≤ 20 分钟（30°C环境）⚠️ | 印尼高温缩短可操作时间 |
| **留缝宽度** | 1.5–3.0mm ⚠️ | 为抗震预留变形空间 |

### 工序流程

**Step 1: 基层处理与找平**
- *描述*：打磨高点，修补裂缝，施工1:4水泥砂浆找平层，使基层平整度达到≤3mm/2m。印尼雨季需先测基层含水率（<8%）方可施工。
- *工具*：研磨机、2m靠尺、含水率测试仪。
- *验收*：基层干燥、平整、无脱模剂残留。

**Step 2: 胶粘剂搅拌（分散）**
- *描述*：使用高性能聚合物改性（C2TE S1/S2级）胶粘剂。严格按厂家水粉比用低速电动搅拌机（≤300rpm）搅拌。浆料必须呈奶油状、不下垂。
- *工具*：低速搅拌机、量具、稠度仪。
- *验收*：无干粉结块；严格遵循说明书规定的熟化（静置）时间。

**Step 3: 双面刮胶（基层与板背）**
- *描述*：在基层（用10–12mm齿形刮板）和板背（用6–8mm齿形刮板）同时刮涂平行条纹。**双面刮胶是确保100%满粘的强制项，不可商议**。
- *工具*：齿形刮板（推荐U型）、抹子。
- *验收*：条纹均匀、连续、无结皮。

**Step 4: 板材就位与定位**
- *描述*：使用专业真空吸盘（根据尺寸至少2–4个）提升板材。将板材侧滑放置于胶粘剂层上，使胶条塌陷融合。
- *工具*：真空吸盘、吸力提升器、可调支架。
- *验收*：定位精度±1mm以内；边角无磕碰。

**Step 5: 振动压实与调平**
- *描述*：使用电动振动压实器（或手动振捣垫）从中心向四周均匀压实板材。立即插入重型调平器并拧紧钳具，达成完美齐平接缝。**振动是排出底部空气的关键**。
- *工具*：振动压实器、激光水平仪、重型调平系统（楔子/卡扣）。
- *验收*：平整度≤1mm/2m；相邻板高低差≤0.3mm ⚠️；卡扣到位。

**Step 6: 养护与保护**
- *描述*：**至少48小时内**禁止上人和放置重物（标准24小时对大板不足）。高湿环境（>80%）下，养护期应延长至72小时以防粘结失效。
- *工具*：防护胶合板、警示带。
- *验收*：无位移；挤出的胶浆已固化。

**Step 7: 柔性填缝**
- *描述*：72小时后移除调平器，使用高性能**环氧基或混合聚合物填缝剂**（禁止普通水泥勾缝）填充接缝，以吸收微地震位移。
- *工具*：填缝刮板、压缝球、海绵。
- *验收*：填缝饱满；颜色完全匹配；无泛碱。

### 验收标准 (QC)

| 验收项 | 标准 | 检测方法 |
| :--- | :--- | :--- |
| **空鼓** | **0%** — 任何空鼓均不可接受 | 全面敲击法（硬币/木锤） |
| **平整度** | 2m靠尺下缝隙≤1mm | 塞尺 |
| **高低差** | 相邻板≤0.3mm | 百分表 / 指尖触感 |
| **胶粘剂覆盖率** | 室内≥90%，室外/湿区≥95% | 随机拉拔测试 |
| **抗震缝宽** | 保留宽度公差±0.5mm | 卡尺 |

### 常见问题与避坑（印尼特化）

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| **空鼓** | 胶粘剂在放置前已表干 / 振动不足 | 小批量搅拌；强制双面刮胶+振动压实器 |
| **开裂（热胀/地震）** | 使用刚性填缝剂 / 留缝不足 | 使用柔性环氧填缝剂；结构柱附近留3.0mm宽缝 |
| **板面翘曲** | 胶层厚度不均 / 阳光直射 | 确保刮齿均匀；安装前避免板材暴晒 |
| **雨季粘结失效** | 环境高湿稀释胶粘剂 | 使用延长开放时间胶粘剂；测含水率；湿度>85% RH时停工 |

### 关联知识（人力、材料与替代方案）

- **[[china-skilled-labor|中国技工]]**：**强制使用**——印尼本地工人普遍缺乏振动压实和吸盘操作的专项培训。
- **主粘结剂**：[[epoxy-adhesive|环氧基C2TE S2级瓷砖胶]]。
- **填缝材料**：[[flexible-grout|混合聚合物填缝剂（R2级）]]。
- **替代方案**：[[mechanical-anchoring-system|机械锚固+粘结复合系统]]（适用于高层外立面）。
