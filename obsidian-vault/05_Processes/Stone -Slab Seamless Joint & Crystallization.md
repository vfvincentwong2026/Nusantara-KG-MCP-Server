# Stone / Slab Seamless Joint & Crystallization（石材/岩板无缝拼接与结晶处理）

> 🤖 本文件为石材镜面处理工法。无缝拼接+结晶处理是高端精装的“最后一道面层工序”，完成后即进入成品保护阶段。

---

## English（EN）

### Core Parameters

|Parameter|Specification|Note|
|---|---|---|
|**Gloss Level (After Crystallization)**|≥70° (marble) / ≥60° (granite)|Gloss meter|
|**Joint Visibility**|Invisible at 1m distance|Visual|
|**Slip Resistance (R Rating)**|R10 (wet) / R11 (dry)|Pendulum test|
|**Polishing Sequence**|50# → 100# → 200# → 400# → 800# → 1500# → 3000#|Diamond pads|
|**Crystallization Compound**|Calcium fluoride-based (for marble)|—|

### Key Workflow

1. **Surface Preparation** → Clean stone surface; repair any chips/cracks with color-matched epoxy filler.
    
2. **Grinding (Coarse → Fine)** → Progress through diamond pads from 50# to 3000#. Each grit removes the scratches from the previous grit.
    
3. **Seamless Jointing** → Open joints to 2–3mm, fill with color-matched epoxy, overfill slightly. Sand flush after curing.
    
4. **Crystallization** → Apply crystallization compound with steel wool pads under high-speed polisher (1500–2500 RPM). Creates calcium fluoride layer with mirror gloss.
    
5. **Final Buff** → High-speed burnishing for final gloss enhancement.
    

### QC Standards

|Criterion|Standard|Method|
|---|---|---|
|**Gloss**|≥70° (marble)|Gloss meter (5 random points)|
|**Joint Quality**|Invisible at 1m|Visual + raking light|
|**Orange Peel**|None|Raking light at 30° angle|
|**Stain Resistance**|No staining after 5 mins|Coffee/oil drop test|

### Common Issues

|Issue|Cause|Solution|
|---|---|---|
|**Low Gloss**|Insufficient pad sequence / Wrong compound|Re-polish with full grit sequence|
|**Joint Visible**|Filler color mismatch / Poor sanding|Re-open; re-fill with matched epoxy|
|**Hologram / Swirl Marks**|Uneven pad pressure|Even pressure; final pass with 3000# + burnishing|
|**Yellowing (Marble)**|Wrong crystallization compound|Use calcium fluoride-based only|

## 中文（ZH）

### 核心参数

|参数|规格指标|备注|
|---|---|---|
|**结晶后光泽度**|≥70°（大理石）/ ≥60°（花岗岩）|光泽度仪|
|**接缝可见度**|1m距离不可见|目视|
|**防滑等级**|R10（湿）/ R11（干）|摆锤测试|
|**研磨顺序**|50# → 100# → 200# → 400# → 800# → 1500# → 3000#|金刚石磨片|
|**结晶剂**|氟化钙基（大理石用）|—|

### 工序要点

1. **表面准备** → 清洁石材表面；色差环氧胶修补破损/裂纹。
    
2. **研磨（粗→细）** → 50#至3000#逐级研磨，每级消除上级划痕。
    
3. **无缝接缝** → 开缝2–3mm，填入调色环氧胶（略高于表面），固化后打磨平整。
    
4. **结晶处理** → 高速抛光机（1500–2500 RPM）+ 结晶剂 + 钢丝棉垫，形成镜面氟化钙层。
    
5. **终抛** → 高速增光处理。
    

### 验收标准

|验收项|标准|方法|
|---|---|---|
|**光泽度**|≥70°（大理石）|光泽度仪（随机5点）|
|**接缝质量**|1m不可见|目视+侧光|
|**橘皮纹**|无|30°侧光检查|
|**耐污性**|5分钟不渗色|咖啡/油滴测试|
