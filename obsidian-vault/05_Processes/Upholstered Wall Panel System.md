# Upholstered Wall Panel System（软包/硬包墙面系统）

> 🤖 本文件为软硬包墙面工法。所有材料须达阻燃B1级；背板须做防霉处理。印尼高湿环境下普通面料会发霉。

---

## English（EN）

### Core Parameters

|Parameter|Specification|Note|
|---|---|---|
|**Panel Thickness**|25–50mm (soft) / 12–20mm (hard)|—|
|**Foam Density**|≥25kg/m³ (soft)|—|
|**Upholstery Material**|Fabric / Leather / PU Leather|All fire-retardant|
|**Fire Rating**|B1 (flame retardant)|Mandatory per SNI|
|**Panel Fixing**|Concealed clips or adhesive|—|
|**Staple Size**|6mm (stainless steel)|Anti-corrosion|

### Key Workflow

1. **Substrate Preparation** → Wall flatness ≤2mm/2m. Install anti-mold backing board.
    
2. **Foam & Fabric Lamination** → In workshop: glue foam to backing board; stretch fabric over foam; staple to back (fabric tension uniform).
    
3. **Panel Installation** → Fix panels to wall using concealed clips or adhesive. Gaps between panels ≤1mm.
    
4. **Edge Finishing** → Install trim/beading at panel edges. Seal perimeter with flexible sealant.
    

### QC Standards

|Criterion|Standard|Method|
|---|---|---|
|**Fabric Tension**|No wrinkles / no sagging|Visual + hand sweep|
|**Pattern Alignment**|Continuous across panels (if patterned)|Visual at 1m|
|**Panel Flatness**|≤1mm/2m (hard) / ≤2mm/2m (soft)|2m straightedge|
|**Fabric Color Consistency**|No batch variation|Visual under 5000K light|

### Common Issues

|Issue|Cause|Solution|
|---|---|---|
|**Wrinkles / Sagging**|Inconsistent fabric tension|Uniform stretching during stapling|
|**Fabric Discoloration (UV)**|No UV protection|Use UV-protected fabric for sun-facing walls|
|**Mold Behind Panels**|No anti-mold backing|Mandatory anti-mold backing board|
|**Fabric Fraying at Edges**|Poor finishing|Seal edges; install trim bead|

## 中文（ZH）

### 核心参数

|参数|规格指标|备注|
|---|---|---|
|**面板厚度**|25–50mm（软包）/ 12–20mm（硬包）|—|
|**海绵密度**|≥25kg/m³（软包）|—|
|**面层材料**|布艺 / 皮革 / PU皮|均须阻燃|
|**阻燃等级**|B1级|SNI强制|
|**固定方式**|隐藏式卡扣或胶粘|—|
|**钉书针规格**|6mm（不锈钢）|防腐|

### 工序要点

1. **基层准备** → 墙面平整度≤2mm/2m；安装防霉背板。
    
2. **海绵与面料复合** → 工厂内：海绵胶粘于背板；面料拉伸包裹海绵；背面钉固（面料张力均匀）。
    
3. **面板安装** → 隐藏式卡扣或胶粘固定于墙面；板缝≤1mm。
    
4. **边部收口** → 安装收边条/压条；边缘涂柔性密封胶。
    

### 验收标准

|验收项|标准|方法|
|---|---|---|
|**面料张力**|无褶皱/无松垮|目视+手扫|
|**花型对齐**|相邻板连续（如有花型）|1m距离目视|
|**面板平整度**|≤1mm/2m（硬包）/ ≤2mm/2m（软包）|2m靠尺|
|**面料色差**|无批次差异|5000K光源下目视|
