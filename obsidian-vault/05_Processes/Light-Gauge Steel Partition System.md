# Light-Gauge Steel Partition System（轻钢龙骨隔墙系统）

> 🤖 本文件为隔墙系统工法。印尼高湿及白蚁高发地区严禁使用木龙骨，必须采用镀锌钢龙骨。

---

## English（EN）

### Core Parameters

|Parameter|Specification|Note|
|---|---|---|
|**Stud Size**|75mm / 100mm / 150mm (depth)|Depends on height & acoustic req.|
|**Stud Spacing**|≤ 600mm (center-to-center)|—|
|**Board Layers**|1 or 2 layers each side|Double-layer for STC ≥50|
|**Board Thickness**|12.5mm (standard) / 15mm (fire-rated)|—|
|**Acoustic Insulation**|Mineral wool (≥50kg/m³)|Mandatory for STC ≥45|
|**Acoustic Sealant**|At all perimeter joints|Prevents flanking noise|

### Key Workflow

1. **Layout & Track Installation** → Mark ceiling and floor tracks with laser. Install U-tracks with acoustic tape underneath.
    
2. **Stud Installation** → Insert C-studs into tracks at ≤600mm spacing. Double-stud at door openings.
    
3. **Service Rough-in** → Run electrical conduits, data cables inside the cavity before boarding.
    
4. **Insulation Installation** → Fit mineral wool tightly between studs. No gaps allowed.
    
5. **First Layer Boarding** → Fix gypsum boards vertically (staggered joints). Screw spacing ≤200mm.
    
6. **Second Layer Boarding** → Apply acoustic adhesive between layers; stagger joints offset from first layer.
    
7. **Joint Treatment** → Fill screw heads and joints; apply tape; feather out 300mm wide.
    
8. **Perimeter Sealing** → Apply acoustic sealant at all wall/floor/ceiling junctions.
    

### QC Standards

|Criterion|Standard|Method|
|---|---|---|
|**Stud Spacing**|≤600mm|Tape measure|
|**Wall Plumb**|≤2mm/2m|Laser level|
|**STC Rating**|≥45 (single) / ≥50 (double)|Sound transmission test|
|**Screw Penetration**|≤0.5mm below board surface|Feeler gauge|
|**Joint Flatness**|≤1mm/2m|2m straightedge|

### Common Issues

|Issue|Cause|Solution|
|---|---|---|
|**Crack at Joints**|Insufficient tape / No staggered joints|Use paper tape; stagger joints ≥300mm|
|**Poor Acoustic Performance**|Gaps in insulation / No acoustic sealant|Ensure tight fit; perimeter sealant|
|**Screw Pop-out**|Over-driven screw|Use screw gun with depth stop|
|**Wall Not Plumb**|Track not level|Laser level track installation|

## 中文（ZH）

### 核心参数

|参数|规格指标|备注|
|---|---|---|
|**龙骨规格**|75mm / 100mm / 150mm（深）|依高度/隔音需求|
|**龙骨间距**|≤600mm（中心距）|—|
|**板材层数**|每侧1或2层|双层STC ≥50|
|**板材厚度**|12.5mm（常规）/ 15mm（防火）|—|
|**隔音填充**|岩棉（≥50kg/m³）|STC≥45强制|
|**隔音密封胶**|所有周边接缝|防侧漏音|

### 工序要点

1. **放线与轨道安装** → 激光定位天地轨道；轨道下贴隔音胶带。
    
2. **竖龙骨安装** → C型龙骨入轨道，间距≤600mm；门洞处双龙骨加强。
    
3. **管线预埋** → 封板前穿强弱电管线。
    
4. **填充隔音棉** → 龙骨间紧密填充岩棉，无空隙。
    
5. **第一层封板** → 石膏板竖向安装（接缝错开），螺丝间距≤200mm。
    
6. **第二层封板** → 层间涂隔音胶；接缝与第一层错开≥300mm。
    
7. **接缝处理** → 填螺丝头+接缝；贴纸带；刮平宽300mm。
    
8. **周边密封** → 所有墙/地/天交接处涂隔音密封胶。
    

### 验收标准

|验收项|标准|方法|
|---|---|---|
|**龙骨间距**|≤600mm|卷尺|
|**墙面垂直度**|≤2mm/2m|激光水平仪|
|**隔音等级**|≥45（单层）/ ≥50（双层）|隔音测试|
|**螺丝沉入度**|≤0.5mm|塞尺|
|**接缝平整度**|≤1mm/2m|2m靠尺|
