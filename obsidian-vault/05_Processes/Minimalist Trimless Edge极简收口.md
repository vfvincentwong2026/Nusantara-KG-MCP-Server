# Minimalist Trimless Edge / Shadow-Gap Baseboard (极简收口)

## English (EN)

### Overview
Trimless edges are the defining detail of high-end minimalism: no baseboard, no door casing — just a crisp 10–15mm shadow gap or a perfectly flush plaster edge meeting the floor. The effect reads as "effortless" only because every upstream trade did its job to millimeter tolerance. In Indonesia, this is the detail most often value-engineered back to baseboards after the first wall turns out wavy — the real prerequisite is screed-leveled substrate, not the profile itself.

### Process Parameters
- **Shadow gap width**: 10–15mm, deviation ≤ 0.5mm over full run ⚠️
- **Substrate verticality**: ≤ 2mm per 2m (mandatory, via [[ribbed-screed-gauging-strips]]) ⚠️
- **Profile embed depth**: flush ±0.5mm with finished wall plane ⚠️
- **Floor junction clearance**: 3–5mm (Indonesia humidity expansion) ⚠️

### Step-by-Step Workflow
1. **Substrate Verification**  
   Verify wall verticality ≤ 2mm/2m before any profile work; reject and re-level if exceeded.  
   - *Tools*: 2m straightedge, laser plane.  
   - *Acceptance*: Full-wall scan pass — **no exceptions, this is the make-or-break gate**.
2. **Edge Layout**  
   Mark the shadow-gap line continuously around the room at finished floor level + gap height; account for floor finish thickness.  
   - *Tools*: Laser level, chalk line.  
   - *Acceptance*: Line deviation ≤ 0.5mm over full perimeter ⚠️.
3. **Profile Fixing**  
   Fix recessed aluminum shadow-gap profiles to the substrate at the marked line; mechanical fixing, never adhesive-only.  
   - *Tools*: Drill, screws, profile cutter.  
   - *Acceptance*: Profile flush ±0.5mm; fixing spacing ≤ 400mm ⚠️.
4. **Plaster Embedding**  
   Embed profile flanges into skim coat with mesh reinforcement at the junction.  
   - *Tools*: Taping knives, mesh tape.  
   - *Acceptance*: No ridge readable under raking light.
5. **Floor Installation Interface**  
   Coordinate with flooring trade ([[wet-method-tiling]] / [[large-format-slab-installation]]): floor edge slides under the profile lip, keeping 3–5mm expansion clearance.  
   - *Tools*: Spacers.  
   - *Acceptance*: Clearance uniform, floor edge fully concealed by profile lip.
6. **Final Finishing**  
   Wall finish (paint/microcement) brought down to the profile edge; clean the gap channel.  
   - *Tools*: Fine brushes, gap cleaning tool.  
   - *Acceptance*: Gap channel free of compound residue; edge line crisp.
7. **Door & Corner Details**  
   Trimless door frames: flush aluminum reveals set before plaster; internal/external corners get dedicated corner profiles.  
   - *Tools*: Corner profiles, laser.  
   - *Acceptance*: Reveal lines continuous through corners, no step.

### Quality Control (QC) Standards
| Criterion | Standard | Note |
| :--- | :--- | :--- |
| Gap width uniformity | 10–15mm, ±0.5mm ⚠️ | Caliper at 1m intervals |
| Profile flush | ±0.5mm to wall plane ⚠️ | Straightedge + feeler |
| Substrate verticality | ≤ 2mm/2m ⚠️ | Pre-gate, Step 1 |
| Edge cracking | Zero cracks at profile junction after 28d ⚠️ | Raking light |
| Corner continuity | No step at corners | Visual + fingertip |

### Common Issues & Prevention
| Issue | Cause | Solution |
| :--- | :--- | :--- |
| Wavy gap line | Substrate not leveled | Mandatory screed leveling pre-gate; no waiver |
| Cracks along profile | No mesh at flange / rigid filler | Mesh reinforcement mandatory; flexible compound |
| Floor edge exposed | Clearance misjudged / floor height changed | Confirm floor build-up thickness before layout |
| Gap clogged with paint | Finishing trade untrained | Gap masking during painting; dedicated cleaning tool |
| Profile dented | Site traffic after install | Protection film until handover ⚠️ |
| Humidity swelling | Gap < 3mm in wet season | 3–5mm clearance, flexible sealant at wet zones ⚠️ |

### Related Knowledge (Labor & Materials)
- **[[china-skilled-labor|China Skilled Labor]]**: mandatory for profile installation (mm-level exposed tolerance).
- **[[indonesian-skilled-labor|Indonesian Skilled Labor]]**: may assist plaster embedding under supervision.
- **Prerequisite**: [[ribbed-screed-gauging-strips|Ribbed Screed Leveling]] — no leveling, no trimless.
- **Alternative**: [[metal-baseboard-installation|Metal Baseboard]] — the honest fallback when substrate budget is limited.
- **Materials**: recessed aluminum shadow-gap profile (Atelier SKU 缺口 ⚠️), corner profiles.

## 中文 (ZH)

### 概览
极简收口是高端极简风的定义性细节：无踢脚线、无门套——只有一道 10–15mm 利落的阴影缝，或墙面与地面的完美齐平交接。"毫不费力"的观感背后，是上游每个工种都做到毫米级容差。在印尼，这道工艺最常在第一面墙做歪之后被"优化"回踢脚线——真正的前提是冲筋找平的基层，而不是型材本身。

### 工艺参数
- **阴影缝宽度**：10–15mm，全程偏差 ≤0.5mm ⚠️
- **基层垂平度**：≤2mm/2m（强制，经 [[ribbed-screed-gauging-strips|冲筋找平]]）⚠️
- **型材嵌入齐平**：与完成墙面 ±0.5mm ⚠️
- **地面交接预留**：3–5mm（印尼高湿膨胀）⚠️

### 工序流程
1. **基层验证**  
   型材施工前验证墙面垂平 ≤2mm/2m，超限退回重找平。  
   - *工具*：2m 靠尺、激光平面。  
   - *验收*：全墙扫描通过——**无例外，这是生死门**。
2. **放线**  
   沿房间连续弹出阴影缝线（完成地面标高 + 缝高），计入地面完成厚度。  
   - *工具*：激光水平仪、墨线。  
   - *验收*：全线偏差 ≤0.5mm ⚠️。
3. **型材固定**  
   内嵌铝合金阴影缝型材沿标线机械固定，严禁纯胶贴。  
   - *工具*：电钻、螺丝、型材切割机。  
   - *验收*：齐平 ±0.5mm；固定间距 ≤400mm ⚠️。
4. **批嵌埋入**  
   型材翼缘埋入批灰层，交接处网格带加强。  
   - *工具*：批刀、网格带。  
   - *验收*：侧光下无可见棱线。
5. **地面工序衔接**  
   与地面工种（[[wet-method-tiling|湿铺]]/[[large-format-slab-installation|大板]]）协同：地面边缘伸入型材唇口下，留 3–5mm 膨胀缝。  
   - *工具*：缝隙卡子。  
   - *验收*：缝隙均匀，地面边缘完全被唇口遮蔽。
6. **面层收口**  
   墙面面层（乳胶漆/微水泥）做到型材边，清理缝槽。  
   - *工具*：细毛刷、清缝工具。  
   - *验收*：缝槽无批灰残留，边线利落。
7. **门套与阴阳角细部**  
   无框门：齐平铝型材门套批灰前预埋；阴阳角用专用角型材。  
   - *工具*：角型材、激光。  
   - *验收*：线条过角连续，无断差。

### 验收标准 (QC)
| 验收项 | 标准 | 备注 |
| :--- | :--- | :--- |
| 缝宽均匀度 | 10–15mm，±0.5mm ⚠️ | 每 1m 卡尺测 |
| 型材齐平 | ±0.5mm ⚠️ | 靠尺+塞尺 |
| 基层垂平 | ≤2mm/2m ⚠️ | Step 1 生死门 |
| 边缘开裂 | 28 天后零裂缝 ⚠️ | 侧光检查 |
| 角部连续 | 阴阳角无断差 | 目测+手触 |

### 常见问题与避坑
| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 缝线波浪 | 基层未找平 | 冲筋找平生死门，无豁免 |
| 型材沿线开裂 | 翼缘未贴网/刚性填缝 | 网格带强制；柔性批嵌 |
| 地面边缘外露 | 预留缝误判/地面厚度变更 | 放线前确认地面构造厚度 |
| 缝内积漆 | 面层工种未培训 | 涂刷时缝槽贴护；专用清缝工具 |
| 型材磕凹 | 安装后现场通行 | 保护贴膜至交付 ⚠️ |
| 高湿膨胀卡死 | 雨季缝 <3mm | 3–5mm 预留，湿区柔性密封 ⚠️ |
