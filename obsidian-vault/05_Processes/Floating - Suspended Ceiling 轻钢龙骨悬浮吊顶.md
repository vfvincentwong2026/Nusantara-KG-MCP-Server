# Floating / Seismic-Resistant Suspended Ceiling (轻钢龙骨抗震悬浮吊顶)
> 🤖 本文件为高精尖工法模板，带 ⚠️ 的参数依据《GB/T 9775 纸面石膏板》及印尼SNI 03-6822-2002抗震建筑标准，具体项目需依结构荷载验算。
---
## English (EN)
### Overview
The floating ceiling is defined by a 100–150mm recessed light slot around its perimeter, optically separating the ceiling plane from the wall. The framework must be **100% galvanized light-gauge steel** — timber is strictly prohibited in Indonesia due to high termite activity and moisture-induced warping. The system incorporates seismic isolation joints at corners and where ceilings exceed 12m in length to prevent shear cracking during earthquakes.
### Critical Process Parameters
| Parameter | Specification | Note |
| :--- | :--- | :--- |
| **Framework Material** | Hot-dip galvanized steel (≥ 275g/m² coating) | Anti-corrosion / Anti-termite |
| **Main Keel Spacing** | ≤ 1200mm ⚠️ | Load-bearing standard |
| **Secondary Keel Spacing** | **≤ 400mm** ⚠️ | Prevents gypsum board sagging in high humidity |
| **Gypsum Board Thickness** | 9.5mm (standard) / 12mm (fire-rated) | **Must be moisture-resistant (MR) grade** for Bali/Java coastal areas |
| **Screw Spacing (Periphery)** | ≤ 150mm ⚠️ | Critical for edge anchoring |
| **Screw Spacing (Internal)** | ≤ 200mm ⚠️ | — |
| **Screw Countersink Depth** | 0.5–1.0mm (paper intact) | Breaking paper causes screw pull-through |
| **Seismic Joint Width** | 5–8mm (at corners & intervals >12m) ⚠️ | Filled with flexible sealant |
### Step-by-Step Workflow
**Step 1: Laser Layout & Positioning**
- *Description*: Use a laser level to project the finished ceiling elevation (usually -150 to -300mm from structural slab). Mark the light-slot perimeter and main keel suspension points precisely.
- *Tools*: Rotary laser level, ink chalk line.
- *Acceptance*: Elevation deviation ≤ ±2mm across the room.
**Step 2: Edge Keel & Suspension Installation**
- *Description*: Install the wall-angle edge keel (UD/C-profile) along the perimeter using expansion anchors. Drill suspension rods (φ8–10mm) into the structural slab — use seismic-grade drop-in anchors, not ordinary plastic plugs.
- *Tools*: Hammer drill, torque wrench, plumb bob.
- *Acceptance*: Anchors secure; edge keel level with laser line.
**Step 3: Main & Secondary Keel Framework**
- *Description*: Clip the main keel (CD-60) onto the suspension rods with hangers, spacing ≤1200mm. Attach secondary keels perpendicularly at ≤400mm spacing via connecting clips. All keels must be interlocked tightly without play.
- *Tools*: Keel nippers, rivet gun (for corner reinforcements).
- *Acceptance*: Framework rigid; no wobble when shaken manually.
**Step 4: Cutting & Prepping Gypsum Boards**
- *Description*: Cut MR-grade gypsum boards to size using a utility knife (score-and-snap method). For edges that are butt-jointed, create a **V-groove chamfer (30°–45°)** on both mating edges — this allows deeper joint compound penetration and prevents surface cracks.
- *Tools*: Utility knife, V-groove router (or manual chamfer plane).
- *Acceptance*: Clean cuts; V-groove depth ≥ 1/2 of board thickness.
**Step 5: Board Installation (Screwing)**
- *Description*: Fix boards to the framework using phosphate-coated drywall screws (minimum 25mm length). Drive screws perpendicularly with a depth-adjustable screw gun. **Screws must be slightly countersunk (paper unbroken)** — overdriving that tears the paper must be immediately removed and re-screwed 50mm away.
- *Tools*: Drywall screw gun with depth-stop nosepiece.
- *Acceptance*: Screw heads flush with board surface; paper intact; no "pop-ups".
**Step 6: Anti-Rust Treatment of Screw Heads**
- *Description*: Apply a specialized **anti-rust putty (epoxy or zinc-rich)** over every single screw head within 8 hours of installation. Indonesia's high humidity will cause exposed screw heads to rust within 48 hours, bleeding through paint.
- *Tools*: Small brush, anti-rust putty.
- *Acceptance*: All 100% of screw heads covered; no metal exposed.
**Step 7: Joint Treatment (V-Groove Filling & Taping)**
- *Description*: Fill the V-groove and all seams with joint compound (setting-type for first coat, drying-type for finish). Immediately embed **perforated paper tape or fiberglass mesh tape** into the wet compound. Apply 2–3 wide passes (150mm, 250mm, 350mm) feathering outwards to achieve a seamless surface.
- *Tools*: Taping knives (100mm, 200mm, 300mm), mixing paddle.
- *Acceptance*: Joints visually flat; no tape bubbles; sanded smooth to ≤1mm flatness.
**Step 8: Seismic Joint Cutting & Sealing**
- *Description*: Where the ceiling meets the wall at corners, or at intervals >12m, deliberately cut a 5–8mm continuous gap through the gypsum board (not to the framing). Back-fill with a **non-hardening elastic sealant (PU/Acrylic)** to absorb seismic shear movement.
- *Tools*: Grinder (for cutting), sealant gun.
- *Acceptance*: Gap clean; sealant flexible and flush.
### Quality Control (QC) Standards
| Criterion | Standard | Inspection Method |
| :--- | :--- | :--- |
| **Keel Spacing** | Main ≤1200mm; Secondary ≤400mm | Tape measure |
| **Overall Flatness** | ≤ 3mm over 2m straightedge | Feeler gauge |
| **Screw Coverage** | 100% with anti-rust coating | Visual inspection + white glove |
| **Paper Integrity** | Zero tears or broken paper around screws | Visual |
| **V-Joint Gap** | 3–5mm (V-shaped) on all butt joints | Caliper |
| **Structural Safety** | Hanger rod pull-out strength ≥ 1.5kN ⚠️ | Random tensile pull-test |
### Common Issues & Prevention (Indonesia-Specific)
| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **Screw Rust Bleed (Yellow/Brown spots)** | No anti-rust treatment / High humidity | **Enforce** anti-rust putty within 8 hours; use stainless-steel screws for bathrooms |
| **Gypsum Board Sagging** | Secondary keel spacing > 400mm / Board absorbs moisture | Tighten spacing to 400mm; use MR-grade boards; ventilate before installation |
| **Corner Cracks (Earthquake)** | Rigid joints without expansion gaps | Mandatory 5–8mm seismic cut at all 90° internal corners |
| **Termite Infestation** | Using wooden furring strips | **Strictly prohibit** timber; use full galvanized steel |
| **Screw "Pop-ups"** | Overdriven breaking paper / Wood shrinkage (not applicable) | Use depth-stop screw gun; replace damaged screws immediately |
### Related Knowledge (Labor, Materials & Alternatives)
- **Labor**: Requires **[[ceiling-system-specialist|Galvanized Keel Specialist]]**. Ordinary woodworkers/carpenters are **not** qualified for this system.
- **Key Materials**: [[moisture-resistant-gypsum-board|MR Gypsum Board (Knauf/Elephant standard)]], [[galvanized-keel-system|CD/UD Keel System]], [[anti-rust-putty|Epoxy Anti-Rust Putty]].
- **Joint Compound**: [[setting-type-joint-compound|Setting-Type Compound]] + [[perforated-paper-tape|Perforated Paper Tape]].
- **Flexible Sealant**: [[polyurethane-sealant|PU Seismic Sealant]].
- **Alternative Ceiling**: [[stretch-ceiling|PVC Stretch Ceiling]] (more moisture-resistant, but less rigid).

## 中文 (ZH)
### 概览
悬浮吊顶通过四周设置100–150mm进深暗藏灯槽，使顶面在视觉上与墙体分离，呈“悬浮”效果。其框架必须为**100%镀锌轻钢**——由于印尼白蚁猖獗且木材极易湿胀干裂，严禁使用任何木方。系统在转角及长度超12m处设置抗震隔离缝，以防地震剪切开裂。
### 核心工艺参数
| 参数 | 规格指标 | 备注 |
| :--- | :--- | :--- |
| **框架材料** | 热镀锌钢（镀层≥275g/m²） | 防腐/防白蚁 |
| **主龙骨间距** | ≤ 1200mm ⚠️ | 承载标准 |
| **副龙骨间距** | **≤ 400mm** ⚠️ | 防止高湿下石膏板下挠 |
| **石膏板厚度** | 9.5mm（常规）/ 12mm（防火） | **巴厘岛/爪哇沿海必须使用耐水（MR）板** |
| **螺丝边距** | ≤ 150mm ⚠️ | 边缘锚固关键 |
| **螺丝中距** | ≤ 200mm ⚠️ | — |
| **螺丝沉入深度** | 0.5–1.0mm（护面纸完好） | 击穿护面纸即报废 |
| **抗震缝宽度** | 5–8mm（转角及长度>12m处）⚠️ | 柔性密封胶填充 |
### 工序流程
**Step 1: 激光放线定位**
- *描述*：使用激光水平仪投射吊顶完成面标高（通常距结构板-150至-300mm）。精确标记灯槽轮廓及主龙骨吊点位置。
- *工具*：旋转激光水平仪、墨斗。
- *验收*：全屋标高偏差≤±2mm。
**Step 2: 边龙骨与吊杆安装**
- *描述*：沿墙安装边龙骨（UD型），用膨胀螺栓固定。在结构板钻孔安装φ8–10吊杆——**必须使用抗震级金属膨管，严禁使用普通塑料胀栓**。
- *工具*：冲击钻、扭力扳手、线坠。
- *验收*：锚栓牢固；边龙骨与激光线平齐。
**Step 3: 主副龙骨框架搭建**
- *描述*：将主龙骨（CD-60）通过吊件挂接于吊杆上，间距≤1200mm。用连接件垂直安装副龙骨，间距≤400mm。所有龙骨咬合紧密、无松动。
- *工具*：龙骨剪、拉铆枪（转角加固）。
- *验收*：框架刚性良好；徒手摇晃无明显晃动。
**Step 4: 石膏板裁切与V型槽处理**
- *描述*：将耐水石膏板按尺寸裁切（划刀切断法）。**所有板材对接边必须开30°–45°的V型坡口**——这能使嵌缝膏渗入更深，有效杜绝表面通缝开裂。
- *工具*：美工刀、V型槽刨刀（或手动刨）。
- *验收*：切口平整；V型槽深度≥板厚的1/2。
**Step 5: 石膏板固定（螺钉作业）**
- *描述*：使用磷化自攻螺丝（长度≥25mm）将板材固定于龙骨。必须使用带限位套筒的电动螺丝枪垂直打入。**螺丝必须略微沉入板面（纸面完好）**——若旋拧过深撕裂纸面，须立即卸除并在50mm外补钉。
- *工具*：带限位深度套筒的螺丝枪。
- *验收*：螺丝头与板面齐平；纸面完整；无“爆钉”现象。
**Step 6: 螺丝头防锈处理**
- *描述*：安装完成后8小时内，对所有螺丝头逐一涂抹**专用防锈腻子（环氧或富锌型）** 。印尼高湿环境下，裸露螺丝头48小时内即会生锈泛黄，透出涂料层。
- *工具*：小毛刷、防锈腻子。
- *验收*：螺丝头100%全覆盖；无金属裸露。
**Step 7: 接缝处理（V型槽填充与贴带）**
- *描述*：用嵌缝膏（首遍用凝固型，面遍用干燥型）填充V型槽及所有板缝。立即将**穿孔纸带或玻纤网格带**压入湿料中。向外刮抹2–3道宽幅（150mm→250mm→350mm）渐层找平。
- *工具*：刮刀（100mm/200mm/300mm）、搅拌棒。
- *验收*：接缝目视平整；无气泡；打磨后平整度≤1mm。
**Step 8: 抗震缝切割与密封**
- *描述*：在顶面转角处及长度>12m的直线段，用切割机在石膏板上切开5–8mm通缝（不切断龙骨）。背衬填入**非固化弹性密封胶（PU/丙烯酸）**以吸收地震剪切位移。
- *工具*：切割机、胶枪。
- *验收*：缝隙干净；密封胶富有弹性且与板面齐平。
### 验收标准 (QC)
| 验收项 | 标准 | 检测方法 |
| :--- | :--- | :--- |
| **龙骨间距** | 主≤1200mm；副≤400mm | 卷尺 |
| **整体平整度** | 2m靠尺下缝隙≤3mm | 塞尺 |
| **螺丝防锈覆盖率** | 100%覆盖 | 目视+白手套擦拭 |
| **纸面完整性** | 螺丝周边纸面零撕裂 | 目视 |
| **V型接缝宽度** | 3–5mm（所有对接缝） | 卡尺 |
| **结构安全性** | 吊杆抗拔承载力≥1.5kN ⚠️ | 随机拉拔测试 |
### 常见问题与避坑（印尼特化）
| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| **螺丝吐锈（黄斑）** | 未做防锈 / 高湿环境 | 强制8小时内涂防锈腻子；卫浴区改用不锈钢螺丝 |
| **石膏板下挠塌腰** | 副龙骨间距>400mm / 板材吸潮 | 收严至400mm；使用耐水板；安装前通风除湿 |
| **转角开裂（地震）** | 刚性连接无伸缩余量 | 所有阴角内角强制切5–8mm抗震缝 |
| **白蚁蛀蚀** | 使用了木龙骨 | **严禁**使用任何木方；全镀锌钢骨架 |
| **螺丝“爆钉”** | 过拧撕裂纸面 / 木收缩（不适用） | 使用限位螺丝枪；损坏螺丝立即补换 |
