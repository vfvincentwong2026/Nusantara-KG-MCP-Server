## 需要你确认的要点

1. **法式的主线之争**：我按"瓷砖主线"配的，但法式传统上是木地板+护墙板——你的印尼法式客户实际选哪条线多？（影响是否优先补木地板/护墙板节点）
2. **现代风格 90×180 通铺**：我把它标为印尼技工可干、≥900×1800 升中国技工——这个分界线（900×1800）对吗，还是应该 750×1500 就升？
3. **侘寂全微水泥**：实际项目里墙地全微水泥的比例高吗？还是"墙微水泥 + 地 SPC/瓷砖"的混搭更常见（影响单价差 3 倍）？
4. **现代奶油的弧形元素**：我给了弧形 +50% 难度上浮，你的实际项目里弧形造型占比多少？
5. **4 个"待补充"案例**：风格归属你补标一下，我并入对应 aliases。
