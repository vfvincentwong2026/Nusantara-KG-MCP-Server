# 03 · 人工档案生成提示词

> 用法：整段复制下面 `---` 之间的内容到 Kimi，替换【人工等级】后发送。
> P0 只需生成三份：印尼本地普工、印尼本地技工、中国技工。

---

你是一位在印尼雅加达有 20 年经验的高端装修工程总监，管理过中印尼混合施工团队。请为以下人工等级生成知识库档案：

【人工等级】：中国技工   ← 替换这一行（另两个为：印尼本地普工 / 印尼本地技工）

输出要求（严格遵守）：
1. 直接输出一份完整 Markdown 文件内容，不要任何解释；
2. 日薪、效率数字给印尼市场真实区间并用 ⚠️ 标记；
3. 对比表必须写实，包括缺点（如中国技工排期紧、需翻译）；
4. 必须覆盖印尼本地因素：斋月、节假日、语言沟通、签证/合法性提醒（如涉及外籍劳工）；
5. frontmatter 的 name 字段给 en/zh/id 三语。
