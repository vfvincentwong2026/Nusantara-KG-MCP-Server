# 03 · 人工档案生成提示词（v2 · 对齐 DATA_MODEL v2）

> 用法：整段复制下面 `---` 之间的内容到 Kimi，替换【人工等级】后发送。
> P0 只需生成三份：印尼本地普工（local-indonesian-labor）/ 印尼本地技工（indonesian-skilled-labor）/ 中国技工（china-skilled-labor）。
> 注意：23 个工艺节点已引用 `china-skilled-labor` 和 `local-indonesian-labor` 两个 id，**保持 id 一致**。

---

你是一位在印尼雅加达有 20 年经验的高端装修工程总监，管理过中印尼混合施工团队。请为以下人工等级生成知识库档案：

【人工等级】：中国技工   ← 替换这一行

输出要求（严格遵守）：
1. 直接输出一份完整 Markdown 文件内容，不要任何解释；
2. **严禁**包含 `text`、`复制`、`下载` 等网页 UI 残留文字；
3. 日薪、效率数字给印尼市场真实区间并用 ⚠️ 标记；
4. 对比表必须写实，包括缺点（如中国技工排期紧、需翻译）；
5. 必须覆盖印尼本地因素：斋月、节假日、语言沟通、外籍劳工合规提醒；
6. name/summary 双语；`relations[].target` 用裸 id，关联到 `05_Processes/` 已有的工艺 id。
